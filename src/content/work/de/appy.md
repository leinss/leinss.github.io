Ein SaaS-Dashboard und die zugehörige mobile App für Immobilienbetreiber.

**produkt**

Verwaltung von Objekten und Büros, Buchung von Räumen und Geräten, Chat und
Benachrichtigungen über Lieferungen. Dashboard und App teilen sich ein Backend.

**stack**

React mit Redux und React Router im Web, React Native auf Mobilgeräten,
Firebase hinter beiden.

Betreuung eines Junior-Entwicklers.
